## Não incluídas

- **Lessie (`people-search`, `lessie-email`)**: o repositório [LessieAI/lessie-skill](https://github.com/LessieAI/lessie-skill) não tem arquivo de licença. Usa os Termos de Serviço do fornecedor e exige conta e CLI externos (`@lessie/cli`). Faz busca de contatos de pessoas reais.
- **Persona Definer, Copy Master, Content Cluster**: aparecem apenas em sites de catálogo, sem repositório de origem com o `SKILL.md`.
- **Market Research, Tone Adjuster, B2B Prospector, Data Analyst, JSON/Markdown Exporter**: não encontrei skill publicada com esses nomes.
